# Sokratus

Минимальный клиент к кабинету вуза: **расписание**, **журнал оценок**, **QR посещаемости**.

Вход в учётку → три модуля. Без ленты, музыки и остального шума официального приложения.

## Стек

- Next.js (App Router) + Tailwind v4 + Motion
- Прокси к REST кабинета вуза (`token` header)

## Запуск

```bash
npm install
npm run dev
# опционально: NEXT_PUBLIC_LMS_URL=https://edu.your-uni.kz
```

Открой [http://localhost:3000](http://localhost:3000), укажи URL кабинета вуза, логин и пароль.

## Как устроено

1. Логин на стороне сервера (Next route handlers)
2. Клиент бьёт в локальные `/api/lms/*`, сервер проксирует на вуз (обход CORS)
3. Для расписания / журнала / QR перебираются известные пути разных версий кабинета

## Замечания

У разных вузов пути API плавают. В ответе API при ошибке есть `tried` — список опробованных эндпоинтов.
